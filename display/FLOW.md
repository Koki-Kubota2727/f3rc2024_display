# F3RC2024 Display システム フロー

## 起動方法

1. `main.html` をブラウザで開く（ダブルクリックでOK）
2. インターネット接続が必要（Google Sheets API を叩くため）
3. スプレッドシート側の担当者が値を更新すると画面が自動更新される

---

## 全体構成

```
Google スプレッドシート (original_sheet)
        ↓ Google Sheets API (5秒ごとにポーリング)
    script.js
        ↓
    main.html に描画
```

---

## スプレッドシートのセルとUIの対応

シート名: `original_sheet`  
`G32〜G46` の列が表示を制御する。

| セル | インデックス | 内容 | 画面上の要素 |
|------|------------|------|------------|
| G32  | [0]  | 左チームの点数（数値）      | 左の点数表示 |
| G33  | [1]  | 右チームの点数（数値）      | 右の点数表示 |
| G34  | [2]  | チェック1（0 or 1）        | check1 画像（現在コメントアウト） |
| G35  | [3]  | チェック2（0 or 1）        | check2 画像（現在コメントアウト） |
| G36  | [4]  | ボナペティ左（0 or 1）     | bon1 画像 |
| G37  | [5]  | ボナペティ右（0 or 1）     | bon2 画像 |
| G38  | [6]  | パイン数・左（0〜5）        | pine1〜5 の表示数 |
| G39  | [7]  | パイン数・右（0〜5）        | pine6〜10 の表示数 |
| G40  | [8]  | チョコ数・左（0〜5）        | choco1〜5 の表示数 |
| G41  | [9]  | チョコ数・右（0〜5）        | choco6〜10 の表示数 |
| G42  | [10] | パンケーキ数・左（0〜3）    | bread1〜3 の表示数 |
| G43  | [11] | パンケーキ数・右（0〜3）    | bread4〜6 の表示数 |
| G44  | [12] | 左チームの大学名（文字列）  | 左下の大学名テキスト |
| G45  | [13] | 右チームの大学名（文字列）  | 右下の大学名テキスト |
| G46  | [14] | タイマー状態（1〜5）        | 中央タイマー表示 |

## タイマー状態（G46の値）

| 値 | 表示 | 動作 |
|----|------|------|
| `1` | `set` | セッティング中の表示 |
| `2` | `1:00` → カウントダウン | 1分のセッティングタイマーが動く |
| `3` | `stop` | 停止表示 |
| `4` | `ready` | レディ表示 |
| `5` | `3` → `2` → `1` → `GO!` → `3:00` → カウントダウン → `FINISH!` | 競技タイマー本番（3カウント後に3分計測開始、音あり） |

タイマーは **値が変わった瞬間にリセット**される（`2` や `5` は状態フラグで再入場を検知）。

## 5秒ポーリングの中身

```
setInterval（5秒ごと）
  ├─ fetchData1(G32) → 左チームの点数を更新
  ├─ fetchData2(G33) → 右チームの点数を更新
  ├─ updateImageDisplay(G36) → bon1 表示/非表示
  ├─ updateImageDisplay(G37) → bon2 表示/非表示
  ├─ updateImageDisplay(G34) → check1 表示/非表示
  ├─ updateImageDisplay(G35) → check2 表示/非表示
  └─ updateObjects()
       ├─ パイン左右の個数を取得してアイコン数を更新
       ├─ チョコ左右の個数を取得してアイコン数を更新
       └─ パンケーキ左右の個数を取得してアイコン数を更新

setInterval（1秒ごと）
  └─ G46 を見てタイマー表示を更新
```

## API キーについて

`script.js` 内に5本のキーがハードコードされている。  
Google Sheets API には1キーあたりの呼び出し制限があるため、用途ごとに分散させている。

| apiKeys[n] | 用途 |
|------------|------|
| [0] | fetchData1（点数左・パイン左・チョコ左・パン左） |
| [1] | fetchData2（点数右・パイン右・チョコ右・パン右） |
| [2] | fetchData3（ボナペティ・チェック画像の on/off） |
| [3] | displayUniversity（大学名取得） |
| [4] | fetchSpreadsheetValue（タイマー状態取得） |

> **注意**: `api.txt` にも同じキーが書かれているが、このファイルは `.gitignore` に追加することを推奨。
